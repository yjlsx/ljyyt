# 🎵 歌曲ID重新排序工具

## 功能说明

这个脚本可以自动重新排序 `script.js` 中所有歌曲的 ID，从 1 开始按顺序分配，并显示实时处理进度。

## 使用方法

### Python 版本（推荐）✅

```bash
# 方法1: 直接执行
python3 reorder-songs.py

# 方法2: 作为可执行脚本
./reorder-songs.py
```

### Node.js 版本

```bash
# 方法1: 使用 Node.js 运行
node reorder-songs.js

# 方法2: 直接执行
./reorder-songs.js
```

## 功能特点

✨ **自动备份**: 处理前自动创建 `script.js.backup` 备份文件  
📊 **进度显示**: 实时显示彩色进度条和百分比  
🎯 **智能识别**: 自动识别并处理不同格式的 ID 字段  
🔄 **顺序重排**: 按照歌曲在数组中的顺序，从 1 开始重新分配 ID  
💾 **安全操作**: 先备份再修改，确保数据安全  
🎨 **彩色输出**: 美观的终端界面，增强可读性

## 恢复备份

如果需要恢复到修改前的状态：

```bash
cp script.js.backup script.js
```

## 注意事项

1. ⚠️ 运行前请确保 `script.js` 文件格式正确
2. 📝 脚本会自动创建备份，无需手动备份
3. 🔍 处理完成后建议刷新网页确认结果
4. 💾 备份文件 `script.js.backup` 可以删除或保留

## 支持的ID格式

脚本可以识别并处理以下格式的 ID：

- `"id": 123`  (双引号)
- `'id': 123`  (单引号)
- `id: 123`    (无引号)

## 常见问题

**Q: 运行后网页不显示歌曲了？**  
A: 请检查浏览器控制台是否有 JavaScript 错误。如有问题，使用备份恢复：`cp script.js.backup script.js`

**Q: 可以多次运行吗？**  
A: 可以！每次运行都会重新从 1 开始排序，并覆盖备份文件。

**Q: 如何验证 ID 是否正确？**  
A: 运行后打开网页，查看歌曲列表是否正常显示。也可以用文本编辑器打开 `script.js` 检查。
